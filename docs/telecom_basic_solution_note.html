Basic Voice Agent Document for Telecom Partner

1. Purpose

This document provides a very basic overview of the proposed voice agent setup and a sample conversational flow for telecom integration discussions.

2. Project Objective

  • Enable inbound and outbound call handling through telecom APIs.
  • Use an AI voice agent to greet callers, collect key details, and route or close calls.
  • Keep call handling simple, reliable, and easy to scale.

3. Basic Scope

  • Telecom platform provides phone numbers, call routing, and webhooks.
  • Voice agent handles conversation in real time.
  • Backend service stores call logs and lead details.

4. High-Level Integration (Simple)

  1. Customer calls telecom number.
  2. Telecom provider sends webhook to our voice agent backend.
  3. Voice agent starts conversation and gathers required information.
  4. Backend stores call summary and outcome.
  5. If needed, call is transferred to a human agent.

5. Basic Conversational Flow (Sample)

5.1 Main Call Flow

  1. Greeting: "Hello, thank you for calling. How may I help you today?"
  2. Intent Capture: Agent identifies reason for call (new inquiry, support, follow-up).
  3. Information Collection: Agent asks for name, phone number, and key requirement.
  4. Qualification / Clarification: Agent confirms details and urgency.
  5. Action Step:
    - If request is simple: provide answer and confirm resolution.
    - If request needs human support: transfer to available representative.
  6. Closure: "Thank you. We have recorded your request. Have a great day."

5.2 Fallback Handling

  • If user is silent: prompt again up to 2 times.
  • If speech is unclear: ask for repeat once in simpler wording.
  • If transfer fails: collect callback time and create follow-up ticket.

7. Data Captured Per Call (Basic)

  • Caller number
  • Caller name (if shared)
  • Intent/category
  • Key notes/requirements
  • Call outcome (resolved/transferred/callback)
  • Timestamp and duration

8. Expected Next Step with Telecom Partner

  • Confirm supported webhook format and event payload.
  • Confirm transfer mechanism (SIP/PSTN/agent queue).
  • Run a pilot with 1 number and test scenarios.

9. Ganpati Hospital Basic Flow with Dialogues

9.1 Use Case

  • Outbound follow-up call for heart checkup enquiries.
  • Brand name used on call: Ganpati Superspeciality Hospital.

9.2 Basic Conversational Flow (Ganpati)

  1. Agent introduces hospital and confirms caller identity.
  2. Agent mentions heart checkup enquiry follow-up.
  3. Agent checks interest in booking.
  4. Agent collects preferred visit day/time and callback number.
  5. Agent confirms next action:
    - If day/time confirmed: mark as booked request and share WhatsApp follow-up.
    - If undecided: note enquiry and schedule callback.
    - If emergency symptoms: stop routine flow and advise immediate emergency help.

9.3 Sample Dialogues

A) Opening + Identity Check

  • Agent: "Hello, this is Roshni from Ganpati Superspeciality Hospital. Am I speaking with [Customer Name]?"
  • Customer: "Yes."
  • Agent: "Thank you. You had shown interest in our heart checkup service, so I am calling to assist with booking."

B) Interest Check + Qualification

  • Agent: "Would you like to schedule your heart checkup?"
  • Customer: "Yes, maybe this week."
  • Agent: "Sure. Which day is convenient for you, and what is your preferred time slot?"

C) Booking Confirmation Path

  • Customer: "Tomorrow morning."
  • Agent: "Noted. I have recorded your request for tomorrow morning. Our hospital team will confirm the exact slot shortly."
  • Agent: "I will also share the hospital address and pre-checkup instructions on WhatsApp."

D) Not Ready / Callback Path

  • Customer: "I need to decide later."
  • Agent: "No problem. I will mark this enquiry for callback. Please share a suitable time for our team to call you again."
  • Customer: "Call me in the evening."
  • Agent: "Perfect, we will arrange a callback in the evening."

E) Pricing/Doctor Detail Query Path

  • Customer: "What is the exact fee and doctor timing?"
  • Agent: "To avoid sharing incorrect information, our front desk will confirm current consultation charges and doctor availability on callback."

F) Emergency Symptom Path

  • Customer: "There is chest pain right now."
  • Agent: "This may be urgent. Please contact emergency services or reach the nearest hospital immediately. We can continue routine booking later."

G) Closing

  • Agent: "Thank you for your time. Your request has been recorded with Ganpati Hospital. Have a good day."
